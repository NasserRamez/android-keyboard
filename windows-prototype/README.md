# Keyboard toy (Windows, Step 1)

1. Install Python 3 from the Microsoft Store (free).
2. Copy `touch_keyboard_toy.py` to your Surface.
3. Open Notepad, then double-click the file (or run `python touch_keyboard_toy.py`).

Try: tap keys with a finger (text appears in Notepad), press keys on a real
keyboard (the on-screen key lights up), tap Shift then a letter.

Set `USE_FINGER_COLORS = True` near the top of the file to preview finger colours.
It never saves or sends what you type.
